# Sources

The rules in this prompt were gathered from the sources below, then merged, de-duplicated and reworded. Most writing and image tips come from practitioner guides rather than formal studies, so treat them as patterns to check, not proof that something was made by AI. Every serious source makes the same point: one sign proves nothing; several together are a signal.

## Writing

- [Wikipedia: Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing), WikiProject AI Cleanup. The most thorough catalogue, with caveats about false positives.
- [humanizer](https://github.com/blader/humanizer) by Siqi Chen (MIT). A Claude Code skill built on the Wikipedia guide; the starting point for this prompt.
- Kobak, González-Márquez, Horvát and Lause, [Delving into LLM-assisted writing in biomedical publications through excess vocabulary](https://arxiv.org/abs/2406.07016), *Science Advances* (2025). Measures the jump in words like "delves", "showcasing", "crucial" and "pivotal" after ChatGPT.
- [tropes.fyi directory](https://tropes.fyi/directory). 49 named patterns, including reasoning leaks, compulsive counting, synonym cycling and fractal summaries.
- [Grammarly: Common AI words and phrases](https://www.grammarly.com/blog/ai/common-ai-words/)
- [Quartz: Words and phrases that give away AI-written text](https://qz.com/words-phrases-give-away-ai-text)
- [Olivia Cal: AI writing tells and word blacklist](https://www.oliviacal.com/post/ai-writing-tells)
- [VoiceMoat: AI tells checklist](https://voicemoat.com/blog/avoid-ai-tells-writers-checklist-2026)
- [The Augmented Educator: Ten telltale signs of AI-generated text](https://www.theaugmentededucator.com/p/the-ten-telltale-signs-of-ai-generated)
- [Riedman Report: How to spot AI writing](https://riedmanreport.substack.com/p/how-to-spot-ai-writing-with-10-easy)
- [Wandering Educators: Top signs writing was generated by AI](https://www.wanderingeducators.com/best/stories/top-signs-writing-generated-by-ai-how-to-fix-it)
- [ExplainX: Top 10 signs of AI-generated text](https://explainx.ai/blog/top-10-signs-ai-generated-text-2026)
- [Lasken Log: False profundity](https://laskenlog.substack.com/p/false-profundity)
- [no-slop skill](https://sharedcontext.ai/skills/external/Byk3y/no-slop) and [slop-detector skill](https://claudeskills.info/skills/athola/claude-night-market/slop-detector/). Both treat AI slop as a density problem rather than a word problem.

## Code

- Ye, Ran, Xu and Zhou, [The Readability Spectrum: Patterns, Issues, and Prompt Effects in LLM-Generated Code](https://arxiv.org/abs/2605.13280) (2026 preprint). Finds LLM code more often has excessive complexity, redundant comments, unknown APIs, redundant variables and extra blank lines.
- [Beyond Correctness: Benchmarking Multi-dimensional Code Generation for LLMs](https://arxiv.org/abs/2407.11470) (2024). Readability as a measure of code quality.
- [The Hidden DNA of LLM-Generated JavaScript](https://arxiv.org/abs/2510.10493). Structural patterns that identify LLM-written code.
- [AquilaX: How to identify vibe-coded code](https://aquilax.ai/blog/how-to-identify-vibe-coded-ai-generated-code) and [How to identify if code is written by AI](https://aquilax.ai/blog/detect-ai-written-code). Including the security anti-patterns: disabled certificate checks, string-built SQL, wildcard CORS, placeholder credentials.
- [Justin McKelvey: How to tell if code was written by AI](https://justinmckelvey.com/blog/how-to-tell-if-code-was-written-by-ai)
- [Diatom Enterprises: How to tell if code is AI generated](https://diatomenterprises.com/blog/how-to-tell-if-code-is-ai-generated/)
- [How to spot code written by AI and why you should care](https://medium.com/@eatsleepprompt/how-to-spot-code-written-by-ai-and-why-you-should-care-b98d329a53db)
- [Signs of AI-generated content: common patterns in literature and code](https://ali-dev.medium.com/signs-of-ai-generated-content-6f672aaab7e0)
- Maryam Salawudeen, *Human-Readable Code and Balanced Commenting Standard*. The commenting rules and the `hasAllowedProtocol` example.
